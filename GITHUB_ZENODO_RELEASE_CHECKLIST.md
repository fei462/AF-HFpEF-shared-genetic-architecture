# GitHub / Zenodo release checklist

Before making the repository public:

- [ ] Replace placeholder author metadata in `CITATION.cff`.
- [ ] Add the final manuscript title and citation when available.
- [ ] Confirm that no credentials, tokens, private participant data, or restricted data are present.
- [ ] Confirm that large third-party datasets are not redistributed.
- [ ] Confirm the final code matches the submitted manuscript Methods.
- [ ] If final Supplementary Figure scripts are available, add them before archival release.
- [ ] Create a GitHub release (for example `v1.1`).
- [ ] Archive that release in Zenodo and obtain a DOI.
- [ ] Replace the provisional text in `CODE_AVAILABILITY_STATEMENT.txt` with the public repository URL and Zenodo DOI.
- [ ] Update `CITATION.cff` with the DOI.
